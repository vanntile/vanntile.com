# vanntile.com

A personal [site](https://vanntile.com) built with [Astro 🚀](https://astro.build/).

It currently integrates the following:

- standard-version
- husky, lint-staged
- Prettier
- TypeScript
- MDX, remark, rehype, mdast, shikiji

## Development

```sh
git config --local core.hooksPath .githooks/
```
